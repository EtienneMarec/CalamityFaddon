# Licences de Calamity Fandom

Ce dépôt mélange plusieurs licences. Chaque fichier indique la sienne, soit par un en-tête `SPDX-License-Identifier`,
soit par `REUSE.toml` (spécification [REUSE](https://reuse.software)). Les textes complets sont dans `LICENSES/`.

| Contenu | Licence |
|---|---|
| Notre code et nos fichiers (par défaut) | GPL v3 ou ultérieure (`LICENSES/GPL-3.0-or-later.txt`), © 2026 Etienne Marec |
| Code repris d'un mod sous GPL v3 (Calamity Hunt, Everquartz' Adventure) | GPL v3, avec le copyright de ses auteurs dans l'en-tête |
| Code repris d'un mod sous MIT (Cataclysm, Infernum, Fargo's Souls) | MIT (`LICENSES/MIT.txt`), avec le copyright de ses auteurs dans l'en-tête |
| Code adapté de Calamity Mod (`Content/Legacy/`) | conditions d'Azafure, LLC (`LICENSES/LicenseRef-Calamity.md`) : **pas** sous GPL |
| Wiki Fandom et notre wiki (`fandom_dump_txt/`, `fandom_dump_extra/`, `wiki/`) | CC BY-NC-SA 3.0 (`LICENSES/CC-BY-NC-SA-3.0.txt`), contributeurs du wiki Calamity Mod |
| Textes et données tirés du wiki (`Localization/`, `WikiData/`, `reports/`) | GPL v3 et CC BY-NC-SA 3.0 |
| Sprites de Calamity et images du wiki | Azafure, LLC et contributeurs du wiki : **aucune licence ne permet de les redistribuer** (en suspens) |
