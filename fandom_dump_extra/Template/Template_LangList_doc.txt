This template stores two lists of language codes: One with all language projects that are ongoing, i.e. still on this wiki, and one with all completed language projects, i.e. languages with an own subdomain. In some [[Help:I18n & l10n for Templates|i18n]] contexts, this information is relevant, e.g. the interwiki linking functionality of translation projects.

== Usage ==
<code>{{(}}langList| ''&lt;function&gt;'' | ''&lt;target lang&gt;'' }}</code>

; First unnamed parameter
One of the following functions:

{|
| {{code|isOnWiki}} || Returns {{code|yes}} if the <code>''&lt;target lang&gt;''</code> is the language code of an ongoing project.
|-
| {{code|isOffWiki}} || Returns {{code|yes}} if the <code>''&lt;target lang&gt;''</code> is the language code of a completed project.
|-
| {{code|isEn}} || Returns {{code|yes}} if the <code>''&lt;target lang&gt;''</code> is neither on-wiki nor off-wiki, i.e. English.
|-
| {{code|onWiki}} || Lists all languages for which <code>isOnWiki</code> is true. See [[gphelp:Extension:ParserPower/List handling functions|Extension:ParserPower]] for parser functions for handling this list.
|-
| {{code|offWiki}} || Lists all languages for which <code>isOffWiki</code> is true.
|}

; Second unnamed parameter
Language to operate on; is usually set to {{tlc|lang}}. Has no effect if the first unnamed parameter is set to {{code|onWiki}} or {{code|offWiki}}, and can be omitted in those cases.
