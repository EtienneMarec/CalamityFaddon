To be placed on top of pages that this page needs to be distinguished with.

== Usage ==
Place {{tl|distinguish|Other page name}} on top of the page.

; Unnamed parameter 1
Another page which the user may confuse this page with.

; Unnamed parameter 2
(Optional) A brief description of the page which the user may confuse this page with.
