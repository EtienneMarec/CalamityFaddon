== Description ==
Use to indicate an [[Death Mode]]-only value. Primarily for use within {{tl|npc infobox}}.

== Usage ==
* <code><nowiki>{{</nowiki> death | ''death mode value''&nbsp; <nowiki>}}</nowiki></code>

If the value changes in Hardmode, place the Hardmode value as the second parameter:
* <code><nowiki>{{</nowiki> death | ''death mode value''&nbsp;| ''death mode hardmode value''&nbsp; <nowiki>}}</nowiki></code>
