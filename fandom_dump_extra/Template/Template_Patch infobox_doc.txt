This template is used to display a patch infobox on [[:Category:Patches|patch pages]].

== Usage ==
{{patch infobox
| title = 1.0.0
| image = Copper Pickaxe.png
| size = 30px
| caption = Example Image.
| patchname = Terraria!
| release = 5/16/2011
| prev = 1.3.0.1
| current = 1.3.5.3
| next = 1.4
}}

; title
Title of the infobox. Defaults to page name.

; patchname
Official name of the patch. Defaults to "Terraria ''&lt;patch number&gt;''", e.g. "Terraria 1.1.2".

; image
Image to display, without <code>[&#91;File:</code>. Defaults to "''&lt;patch number&gt;'' Banner.png/jpg", if possible.

; size
Size of the image.

; caption
Caption to display underneath the image. Rarely used.

; release
Release date of the patch; should be in the format {{code|m/d/yyyy}}.

; prev
Number of the previous patch in the version chronology. The template determines this automatically (based on [[:Category:Patches]]), so this parameter is only to be used if there is an anomaly.

; current
Number of the current patch in the version chronology. Defaults to page name, so this parameter is only to be used if there is an anomaly. Mainly affects the automatic generation of the previous and next patch numbers.

; next
Number of the next patch in the version chronology. The template determines this automatically (based on [[:Category:Patches]]), so this parameter is only to be used if there is an anomaly.

; cate
By default, the page is only categorized in [[:Category:Patches]] if it is in mainspace. Set this parameter to {{code|force}} to always categorize it, regardless of namespace, or to {{code|no}} to prevent this categorization.

; pair
The version number of the respective Music or Main Mod version. Do not include [[ ]] as these are added by the infobox, however (music) is needed when linking to Music Mod patch note pages.
