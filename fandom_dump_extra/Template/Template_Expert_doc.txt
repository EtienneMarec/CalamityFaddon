== Description ==
Use to indicate an [[Expert]]-only value. Primarily for use within {{tl|npc infobox}}.

== Usage ==
* <code><nowiki>{{</nowiki> expert | ''expert value''&nbsp; <nowiki>}}</nowiki></code>

If the value changes in Hardmode, place the Hardmode value as the second parameter:
* <code><nowiki>{{</nowiki> expert | ''expert value''&nbsp;| ''expert hardmode value''&nbsp; <nowiki>}}</nowiki></code>
