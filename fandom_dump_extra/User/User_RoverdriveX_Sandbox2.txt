The Calamity Mod contains several instances where a damaging aura appears around a [[weapon]], the player, or an [[enemy]]. This aura can be visible or invisible, and it may inflict a [[debuff]]. The auras are always circular in shape, but may vary in size and damage-per-second.

== Notes ==
*The revives have an order of priority in which they get triggered: Nebulous Core is always triggered first, God Slayer is triggered only if Nebulous Core did not, Silva is triggered only if the former two did not, and Permafrost's Concoction is triggered only if all other options did not.
*[[Armageddon]] and [[Supreme Calamitas]]' [[lore item]] instant death effects bypass all revives.
*Instantly dying to [[The Devourer of Gods]]' head in [[Death Mode]] and the [[Boss Rush]] does ''not'' bypass revives, allowing the player to survive contact with it.
