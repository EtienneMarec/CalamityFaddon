== Notes ==
*Tainted Potions '''cannot''' be used if their untainted counterparts are active and vice versa.

== Trivia ==
*The Tainted Potions are a reference to tainted characters from ''[[wikipedia:The Binding of Isaac: Rebirth|The Binding of Isaac: Repentance]]''.
**The Tainted Heartreach Potion's effect is a reference to an item from an undisclosed Aftebirth mod.
**The Tainted Love Potion's effect is a reference to Venus, which makes nearby enemies attack each other.
**The Tainted Sonar Potion's effect is a reference to the Glitched Crown, which makes pedestal items rapidly cycle into each other until picked up.
**The Tainted Wrath Potion's effect is a reference to the PAC1F1SM seed, which has a similar mechanic.
*The Tainted Luck Potion's effect is a reference to the ''[[wikipedia:Minecraft|Minecraft]]'' YouTuber Dream, who is infamous for his luck of finding Ender Pearls.
*THe Tainted Rage Potion's effect is a reference to Purity from the Infernum Mod.
