The '''Helios partisan''' is a craftable Epilogue [[spear]] that applies a unique and powerful [[Debuff]]. When used with the primary fire (left click) it uses a custom swing animation that uses a downwards, then an upwards swing, both unleashing homing tuning forks, followed by thrusting forwards and firing a deathray. However, when held it will constantly apply the user with [[Irradiated]]

== Notes ==
*The primary fire is best used against multiple targets, since the beam can pierce all of them, while the secondary is best used for single targets.
*As the beam can easily sweep almost all the screen, it can be used to hit particularly fast targets.

== Trivia ==
*The reason that Irradiated is inflicted on the wielder is due to the large amount of [[wikipedia:Electromagnetic radiation|electromagnetic radiation]] that the sun emits.
