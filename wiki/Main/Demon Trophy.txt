The '''Demon Trophy''' is a [[Summoning items|summoning item]] dropped by [[Supreme Calamitas]] if the world is not in [[Hardmode]]. It allows the player to summon the [[Future bosses]].

== Notes ==
*The item is intended to be obtained during a "Hardmodeless" run of the mod, a challenge run where the player avoids killing the [[Wall of Flesh]] to enter [[Hardmode]].

== Trivia ==
*The Demon Trophy is recycled content from the main Calamity Mod, having originally been a removed item. This is similar to the future bosses, which it is used to summon.
