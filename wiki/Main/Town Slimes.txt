== Names ==
The Town Slimes may have any of the following names:

*'''Astro Slime''': Spacey, Star, Sky, Sagittarius, Saga, Shuttle, Saturn, Solaris, Spiral, Supernova, Sedna, SOS, Susy

*'''Cataraslime''': Sanguine, Slaughter, Sacrifice, Scarlet

*'''Ninja Slime''': Slipstream Sam, Sasuke, Sine, Sekiro, Sakura, Slash, Shadow, Shade, Shatter, Strike

*'''Stiriatic Slime''': Stiry, Suffery, Stony

*'''Threatening Slime''': Surge, Scatter, Spore, Silicon, Siligone, Swarmer, Salvo, Smite, Serpulo, Scorch, Spectre, Sceptre, Sublimate, Segment

*'''Toxic Slime''': Snatcher, Snapper, Sulphur, Slobber, Sanguinos, Splooge, Sediment, Scrappy, Scratch, Slop

== Trivia ==
*The Astro Slimes quote "... .-.. ..- .-. .--. / ... .-.. --- .-. .--.", when translated from morse code, says "slurp slorp".
*Threatening Slime is a reference to Crawler from Mindustry
**Its name "Siligone" is a reference to a popular mindustry meme that players always run out of silicon
**Its other names are references to other Mindustry things like turrets, items or the planet Serpulo
*Cataraslime is a reference to the [[Catarachedrae]] covering
*Many of Ninja Slimes names are references to other media
**Slipstream Sam is a reference to the character Jetstream Sam from Metal Gear Rising.
**Sasuke is a reference to a character of the same name from Naruto.
**Sekiro is a reference to the game Sekiro: Shadows Die Twice
**Shadow is a reference to a character of the same name from the Sonic the Hedgehog series.
*Despite many references towards the Toxic Slime biting things, it does not appear to have a mouth.
