'''The True Jewel''' is a Godseeker Mode [[NPC]] vendor that will spawn right after the [[Abyssal Jewel]] is defeated. 

When threatened by [[enemies]], he will defend himself with [[Cutter's Gift]].

==Notes==

*When [[Abyssal Jewel]] spawns, The True Jewel will die.
*If you use [[The True Lantern]] near him, He will half all the prices.
*The True Jewel's favorite biomes are [[Sky Abyss]] and [[Sunken Sea]], His least favourite biomes are Desert and Underworld.

==Trivia ==
* The True Jewel is internally referred to as "PHOS".
* The True Jewel has a brother, The ancient Cutter.
* The True Jewel likes when it's calm.
* Despite him saying that [[Weaver Lac]] is edible, it is not ingame.
* He is a human version of Abyssal Jewel boss.
* When the Abyssal Jewel spawns, A different death message will appear saying "Aquelt, The True Jewel didn't feel so good".
