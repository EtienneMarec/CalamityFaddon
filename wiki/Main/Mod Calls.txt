'''Mod Calls''' are special functions that can be used with tModLoader's <code>.Call()</code> function to get or set different values from other mods. This page lists the Mod Calls that are provided by the Calamity Mod along with what they are used for.

Note that Spy damage and Spy crit are affected by [[Spy#Throwing Class Compatibility|vanilla Throwing stats]], and adding to Spy stats through these calls will add on top of any throwing stats the player is given.

An asterisk (*) after a parameter type indicates that the function accepts multiple arguments of that type at once. Optional arguments will be specified, along with their default value if applicable.
