The '''XO-Tell''' is a usable [[tool]] that is obtained by having the [[Archivist]] fix the [[Derelict Brick]] with 2 [[Energy Core|Energy Cores]].

When used, a menu will pop up with selectable options. The first option is '''Call''', allowing you to contact [[Town NPCs]] you have met. The second option is '''Message''', which stores messages sent by you and ones received from NPCs.

==Controls==
Use the arrow keys or click on the arrows on the screen to choose which option to select. The arrow keys can also be used to scroll if viewing a long message.

Pressing {{key|enter}} will select the option. Using {{key|backspace}} returns you to the previous page while {{key|esc}} sends you to the main menu.

==Contacts==
There are specific NPCs you can call after they move in. While an NPC is unavailable, the following message will appear: '''The number you are calling is currently unavailable. Call back another time.'''
