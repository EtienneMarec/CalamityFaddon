== Description ==
This template is used to produce a total [[tgc:Coin|coin]] value number from values entered using the coin templates: {{tl|cc}} {{tl|sc}} {{tl|gc}} {{tl|pc}}. It essentially converts coins to their Copper Coin values and adds them together, displaying the total Copper Coin value for all coins entered.

This is primarily for use in {{tl|dpl}} listings, to produce values for <code>data-sort-value</code> in a sortable table's "sell value" column, which can enable accurate sorting where coin values are displayed by coin templates. See [[Melee weapons/dpl]] for an example of the code, and [[Swords]] for an example of the accurate sorting it can produce. 

This template takes a single parameter: a string of one to four coin template calls. The complete contents of most "sell" fields in {{tl|item infobox}} can be used as this parameter.

Example:
* <code>{{tl|coin total| {{tl|gc|12}} {{tl|sc|20}} {{tl|cc|50}}&nbsp; }}</code> 
Produces:
* {{coin total|{{gc|12}} {{sc|20}} {{cc|50}} }}
