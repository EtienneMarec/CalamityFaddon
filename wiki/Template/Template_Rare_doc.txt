This template re-creates the '''Rarity''' ( <code>rare =</code> ) field from [[Template:Item infobox]], producing a colored Rarity label, but allows it to be placed independently. This template can also add pages to the rarity categories.

== Usage ==
Enter the rarity number as a parameter. Use the same number as you would for the infobox (see [[rarity]]).
 
'''When used in a sortable table's "rarity" column,''' add <code>|sort=yes</code> to each {{tl|rare}} template. This will automatically add a sort key that will correct the rarity column's sort order. 

'''If you want to add pages to the rarity categories''', add <code>|cat/cate/category=y/yes</code> to each {{tl|rare}} template, or add <code>|cat/cate/category</code> as unname parameter 2.

----
;Example 1: 
* <code><nowiki>{{rare|2}}</nowiki></code>
Produces:
*{{rare|2}}
----
;Example 2:
* <code><nowiki>{{rare|q}}</nowiki></code> or <code><nowiki>{{rare|quest}}</nowiki></code>
Produces:
*{{rare|q}}
----
;With category:
* <code><nowiki>{{rare|8|category}}</nowiki></code> or <code><nowiki>{{rare|cat=y|8}}</nowiki></code>
