== Usage ==
All variables except Type are optional. 

* The {{code|image}} parameter replaces the main image. A single bare filename must be entered, without any other code. 
* The {{code|imagealt}} parameter replicates the functionality of the {{code|image}} parameter in {{tl|item infobox}}. It replaces the main image, but takes any code. Multiple images can be provided, and/or text and other formatting. Images specified using {{code|imagealt}} require the full {{code|[[File: ]]}} markup.
