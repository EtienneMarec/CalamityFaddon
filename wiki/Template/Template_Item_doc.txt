An all-in-one template for display item name/icon/link.

By default, displays a link to the item and adds an item icon in front of it.

== Usage ==

All parameters are optional. Despite this, some combinations are invalid and may cause errors.

See examples below for more details.

; unnamed parameter 1
Default item display name, link target, and image file name.

; unnamed Parameter 2
Custom link text, which can include line breaks (&lt;br />) and other wikitext. If an 's', 'es', 'ies' or 'ves' is passed as the custom text, it will be appended to the end of the item name.

; mode
Display mode. It can be:
* '''<code>image</code>'''(Preferred) or '''<code>imageonly</code>''' or '''<code>onlyimage</code>''' means only image will be displayed;
* '''<code>text</code>'''(Preferred) or '''<code>noimage</code>''' means no image will be displayed;
* '''<code>table</code>'''(Preferred) or '''<code>2-cell</code>''' will output 2 cells code for table. This is roughly a shortcut for <code><nowiki>{{item|mode=image|itemname}} || {{item|mode=text|itemname}}</nowiki></code>
* '''<code>htmltable</code>'''(Preferred) or '''<code>html-2-cell</code>''' is similar to '''<code>table</code>''', but will produce a result suitable for html tables instead of [[mw:Help:Tables|mediawiki tables]] (roughly a shortcut for <code><nowiki>{{item|mode=image|itemname}} </td><td> {{item|mode=text|itemname}}</nowiki></code>);
Use preferred values as much as possible to get the best performance.

; image
image filename, no brackets nor "File:"(must include file extension, eg. Diverman.png). 

You can specify multiple images, just seperate filenames with slashes(eg. Diverman.png/Soul Forge (placed).png). 

; size
Custom graphic size (Read [https://en.wikipedia.org/wiki/Wikipedia:Extended_image_syntax Extended image syntax] for details).

You can specify multiple sizes, just seperated with slashes(eg. 32px/24x24px).

When multiple images specified:
* If only one size specified, it will apply to all images
* if size is less then image, extra images will be displayed as if they don't have size argument
* if size is more then image, extra sizes will simply be ignored.

; ext
image file extension, default is '''png'''. Only valid when there is no '''image''' input.

; link
Custom link target. If blank given(i.e. '''<code>|link{{=}}|</code>'''), it will be no link(See example below).

; nolink = y/yes
Same as '''<code>|link{{=}}|</code>''', only valid when there is no '''<code>link</code>''' input. If you use '''<code>|link{{=}}somelink|nolink=y</code>''', it will be ignored.

; anchor = y/yes
If set, will create an anchor for '''<nowiki>{{{1}}}</nowiki>'''.

; note
Extra note text. By default, it will displayed as smaller and gray text between item name and platform icons , and without link on it.

; note2
Another note text. By default, it will displayed as gray txt in normal size, without link, and always take a single line.

; wrap = y/yes
Only valid when there is no '''note2{{=}}''' input. If set, note will be displayed in new line.

; class
Custom Css class(es). There're some predefined classes for certain formatting purpose(see examples below). You can add yours if needed.

; css or style
Custom css style rules.

== Change default options ==

You can use '''{{tl|item/options}}''' to set/get and reset some options' default value.

=== Usage ===

* Set: '''<code><nowiki>{{item/options|nolink=y|...}}</nowiki></code>''' or '''<code><nowiki>{{item/options|set|nolink=y|...}}</nowiki></code>''' 
* get: '''<code><nowiki>{{item/options|get|nolink}}</nowiki></code>'''
* reset: '''<code><nowiki>{{item/options|reset}</nowiki>}</code>''' or '''<code><nowiki>{{item/options|resetall}}</nowiki></code>'''

<div style="color:red">'''NOTE: In order to avoid unwanted influences, it is very important to reset options as soon as possible. Especially in the template, you should reset options before the template ends.'''</div>

All parameters:

; unnamed parameter 1
Action. '''<code>get</code>''' or '''<code>load</code>''' means get the current value of a option, '''<code>reset</code>''' or '''<code>resetall</code>''' means reset all options to default value, other values(include none. if you want, recommend to use '''<code>set</code>''' for better readability) means set options' value.

; unnamed Parameter 2
The name of option which you want to get its value, only valid when action is '''get'''. Can be '''<code>mode</code>''', '''<code>wrap</code>''', '''<code>nolink</code>''', '''<code>class</code>''', '''<code>css</code>''' or '''<code>style</code>'''.

; mode
Only valid when action is '''set'''. Set the default value for {{tl|item}}'s '''mode''' parameter. You can use any valid value for {{tl|item}}'s '''mode''' parameter, and a invalid value(recommend to use '''<code>default</code>''', '''<code>all</code>''', or '''<code>both</code>''' for better readability) means change the mode back to default. See {{tl|item}}'s '''<code>mode</code>''' parameter.

; wrap = y/yes/n/no
Only valid when action is '''set'''. Turn on/off line wrap. See {{tl|item}}'s '''<code>wrap</code>''' parameter.

; anchor = y/yes/n/no
Only valid when action is '''set'''. Turn on/off anchor. See {{tl|item}}'s '''<code>anchor</code>''' parameter.

; nolink = y/yes/n/no
Only valid when action is '''set'''. Turn on/off no link option. See {{tl|item}}'s '''<code>nolink</code>''' parameter.

; class
Only valid when action is '''set'''. Default value for '''<code>class</code>'''. See {{tl|item}}'s '''<code>class</code>''' parameter.

; css/style
Only valid when action is '''set'''. Default value for '''<code>css</code>'''. See {{tl|item}}'s '''<code>css</code>''' parameter.

See examples below for more details.
